## Example Question

### Numbers List

Given:

```python
numbers = [10, 20, 30, 40, 50]
```

Tasks:

1. Find the sum of the numbers.
2. Find the largest number.
3. Find the smallest number.
4. Empty the list.

Example output:

```text
Sum: 150
Largest: 50
Smallest: 10
List after emptying: []
```

## How to Run the Programs

### 1. Install Python

Download Python from:

[https://www.python.org/downloads/](https://www.python.org/downloads/)

### 2. Clone this repository

```bash
git clone https://github.com/thejuspk07/My-python-basics.git
cd My-python-basics
```

### 3. Run a Python file

```bash
python basics.py
```

You can also run a file inside a folder:

```bash
python Loops/for_loop/count_long_words.py
```

On some systems, use:

```bash
python3 basics.py
```

## Recommended File Naming Style

Python files in this repository follow a problem-based naming style.

Good examples:

```text
count_long_words.py
count_vowels_in_each_word.py
find_and_replace_word.py
print_title_case.py
```

Meaningful filenames make it easier to understand the purpose of each program.
